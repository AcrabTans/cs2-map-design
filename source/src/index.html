      天际线Ⅱ地图规划设计器
      v0.4.0 · Windows x64 · Tauri 绿色版

      本项目采用许愿式编程。为《Cities: Skylines II》玩家提供二维地图规划、工程管理和游戏内建设参考。

      程序源码采用 MIT 许可。第三方组件沿用各自的许可，详见发布包中的 LICENSE、THIRD_PARTY_NOTICES.md 和 asset-codecs。
      数据与工作流
      工程、底图和提取结果保存在本地。内置二维轮廓来自游戏资产。Carto 用于交换地图数据，Image Overlay 用于把导出的 PNG 叠加到游戏中，供手动建设参考。

      操作说明

      从游戏地图开始
      1. 先在游戏里用 Carto 导出数据，再从「文件 → 导入 Carto 文件夹」选中导出目录。可读取 Shapefile、高程 Elevation.tif 和水深 Depth.tif。
      2. 在「图层 → 导入底图」加入正方形图片，在左侧「地形」切换显示。工程名称和地图边长在「文件 → 工程设置」调整。
      3. 用 Ctrl + S 保存工程。首次保存选择位置，再次保存写回已打开的工程。另存一份可用 Ctrl + Shift + S。
      绘制、调整和显示图层
      • 左侧选图层，右侧查看属性、对象、名称与标签开关，并开始绘制。地块和用地可画边界，路网可画线，建筑可使用内置投影。
      • 单击添加节点，双击或按 Enter 完成，Esc 取消。选择对象后可拖动整体或节点，双击线段插入节点。
      • 「编辑」集中管理参考网格、吸附、名称与标签、预留走廊、缩放和全屏。底图管理、图层管理和区块透明度在「图层」。
      • 用图层开关控制地图显示。导出规划图前，先在地图上确认想保留的图层。
      摆放建筑、提取资产和取名
      • 从左侧建筑资产库打开资产包，在右侧选建筑，单击地图摆放。R 旋转 90°，Shift + R 旋转 15°，右键取消本次选择。
      • 在「工具 → 资产提取」选第三方 .cok 或文件夹，再选输出文件夹。模型和定义都在包内时，可提取二维 .cs2assets。从「资产 → 导入建筑资产包」把结果加入当前工程。
      • 在「工具 → 取名工具」选择风格、对象和语言，每批可生成 16、32 或 64 个名称。「查看全部」支持搜索和翻页，可复制或应用到选中的对象。
      更新 Carto 现状与导出规划
      • 从游戏再次导出同一张地图后，用「文件 → 导入 Carto 文件夹」更新游戏现状，手绘规划会保留。「图层」也可单独导出或叠加导入手绘规划。
      • 从「文件」导出 Carto Shapefile 或 2048、4096、8192 像素的 PNG。PNG 会按可见图层输出整图。
      • 把 PNG 放进 Image Overlay 的 Overlays 目录，在游戏里刷新列表并选择图片，再对照叠图建设。

      资产包管理

      管理当前工程的资产包。移除可撤销，保存工程后生效；不会删除导入源文件或提取器输出。

      图层管理

      管理当前工程的显示、锁定和名称标签。点击分类名称可返回右侧属性与对象列表。

      底图管理

      正方形图片按同一地图范围对齐；可以选择、重命名或从工程中移除底图。移除可撤销，原图片文件保留。
