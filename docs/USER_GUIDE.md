# 地图规划设计器使用手册 · v0.4.0

解压到可写目录后运行 `MapDesign.exe`。程序启动时检查 Microsoft Edge WebView2，缺少时可从提示打开微软下载页。安装运行时后重新启动即可。若随包附有 `WebView2Loader.dll`，请与 EXE 放在同一目录。

- **工程**。用“文件”打开 `.cs2map` 或工程文件夹，或进入“工程设置”调整名称和边长。`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。旧版工程可以打开，保存时保留图层、底图、地形、二维建筑和属性。要保留历史三维数据，可用另存为创建新工程。
- **导入**。通过“图层”导入正方形底图或 Carto 文件夹。可识别 Shapefile、Elevation.tif 和 Depth.tif，更新同一张地图的 Carto 现状时保留手绘规划。
- **绘制**。从左侧选图层，在右侧选择绘制操作。单击添加节点，Enter 或双击完成，Esc 取消。V 选择、H 平移、M 测距。拖动节点或对象修改，Delete 删除，Ctrl+Z 撤销。
- **编辑与显示**。网格、吸附、名称与标签、预留走廊、缩放和全屏都在“编辑”菜单。区块透明度、底图和图层管理在“图层”菜单。
- **建筑**。内置 21 包、6280 项二维资产。内置 DLC、官方资产包、第三方资产包默认折叠。搜索包名后选择建筑，单击地图摆放，R 或 Shift+R 旋转，右键取消。导入 `.cs2assets` 或 JSON 投影文件后，可在右侧改归类。
- **第三方资产提取**。在“工具 → 资产提取”选择 .cok 文件或文件夹，再选择输出文件夹。每包生成一个二维 .cs2assets，可从“资产 → 导入建筑资产包”使用。适用于建筑定义和模型都在包内的第三方资产。
- **取名**。在“工具 → 取名工具”选择 14 种地区风格和 23 类对象，支持中英对照，每次随机生成 16、32 或 64 个名称。点“查看全部”可以在当前风格、对象类型和语言下搜索或翻页，也可以复制名称或应用到选中的可编辑对象。
- **导出**。从“文件”导出七组 Carto Shapefile 或 2048、4096、8192 PNG。PNG 可放到 Image Overlay 的 `Overlays` 目录供游戏中对照建设。

程序的 WebView2 配置放在 EXE 旁的 `userdata/webview`。项目文件由用户选择位置保存。程序内的“帮助 → 操作说明”提供快捷键和操作提示。

Tauri 版保存时仅对高程和水深 GeoTIFF 做无损压缩，地图对象、设置和 PNG 按原格式保存。已内置的相同资产定义由程序提供，第三方资产包及本地修改过的定义随工程保留。工程文件夹的清单只引用需保留的资产包，原有资产文件留在磁盘上。
