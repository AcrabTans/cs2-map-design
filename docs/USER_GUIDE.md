# 天际线Ⅱ地图规划设计器

**v0.1.0 · Windows x64 · 绿色免安装版**  
发布日期：2026-10-31

用于《Cities: Skylines II》的独立地图规划工具。支持二维路网与用地设计、Carto 数据导入、建筑资产摆放和三维只读预览，并内置本地建筑资产提取器。

这是独立规划工具，不是游戏 Mod。规划修改不会直接写回游戏。首次发布，尚未完成万栋建筑及所有资产包的压力与兼容性测试。

## 1. 运行要求与启动

- 面向 Windows 10 / 11 的 64 位系统；本版本在 Windows 11 x64 环境开发验证。
- 三维预览需要支持 WebGL 的图形环境。大型工程的体验取决于内存、CPU 和显卡性能。
- 日常使用无需另装浏览器、Node.js、Python 或 npm 依赖。
- 本地打开、编辑、提取和保存不需要联网，也不调用 AI 服务。

启动步骤：

1. 将 ZIP **完整解压**到有写入权限的普通文件夹，不要直接在压缩包里运行。
2. 双击 `MapDesign.exe`。
3. 从“文件”新建或打开工程，或从“图层”导入底图、Carto 文件夹。
4. 编辑后按 `Ctrl+S` 保存。

发布包不附带个人工程、游戏原始文件、模组资产或示例地图，首次启动显示空白工程。

搬迁时带走整个程序文件夹，不能只复制 EXE。EXE 旁的 DLL、PAK、`locales` 等是运行依赖，不要单独删除。程序不注册开机启动、不安装后台服务。

## 4. 图层分类与配色

| 大类 | 内容 |
| --- | --- |
| 地块 Area | 大片区、小片区、手绘功能区块、游戏地块 |
| 路网 Network | 铁路、水路、高速、主干道、次干道、支路、小路、地铁及立交预留范围 |
| 建筑 Building | 教育、住宅、医疗、警务、消防、市政、产业、商业、文化体育、景观及其他建筑 |
| 交通 Route | 公交、地铁、客运铁路、水上、航空及其他运营线路 |
| 地形 Terrain | 底图选择、Elevation 高程、Depth 水体、陆地／水体简图 |
| 用地 Zoning | Carto 导入的 `Zoning_Boundary` 用地区划 |

- 大类及子类前的勾选控制显示。关闭的对象不参与地图绘制，关闭的地形图片不创建绘图节点；数据仍保留在工程中。
- 展开三角用于展开子类；点击分类名称，在右侧查看属性及对象列表。
- 地块、建筑、路网、交通大类右侧提供“小类显示配色”。修改后统一对应小类的显示颜色，不改写对象保存的原始颜色；`↺` 恢复原始／默认配色。
- 道路分别设置地面、高架／桥梁、隧道颜色。高架较浅、隧道较深，地面不描边；铁路使用黑白组合。
- Route 是叠加在道路上的细运营线路，不是道路几何本身。
- 图层配色、显示状态随工程保存，颜色修改支持撤销。
- 红绿灯及其标签默认不参与地图绘制。

图层透明度为零与关闭图层不同。需要减少绘制负担时，请直接取消显示勾选。

## 5. 二维绘制与编辑

选择左侧具体图层后，在右侧选择绘制操作。单击添加节点，按 Enter 或双击完成；多边形至少三个点，线至少两个点。Zoning 导入子层用于查看和编辑已有区划，手绘功能区块在 Area 下创建。

选择对象后可改名称、属性、颜色、道路等级和结构等。拖动节点调整边界，拖动对象整体移动，双击边缘插入节点。按 Delete 删除选中对象或节点。节点吸附和 500 m 参考网格可在左侧开关中设置。

道路交叉按层级显示：同层公路可形成平交，不同层级表示上下交错。层级数字越大越在上方；留空时按地下、地面、高架的默认层级。铁路、水路、地铁交叉不会自动当作普通道路互通。

立交可先用多边形标出预留范围，再进入范围内细化。范围内的对象及导入几何会检查是否越界。工具不自动生成完整立交匝道。

区块面积使用平方米或平方公里。地图工程默认边长为 **14.336 km**；可在工程设置中检查地图参数。底图分辨率不改变工程的米制坐标，导入时应确认覆盖同一个完整正方形区域。

## 6. 底图与 Carto 导入

### 普通底图

从“图层 → 导入底图…”选择正方形 PNG、JPEG 或 WebP。不同分辨率按同一完整地图范围对齐，不做自动地理配准。导入多张后，在“地形 Terrain”中切换底图，也可选择无底图。

### Carto 文件夹

[Carto 项目与说明](https://github.com/taipei-native/Carto)：用于导出《Cities: Skylines II》的空间矢量与地形栅格数据。

导入整个 Carto 导出目录，保留 Shapefile 配套文件：`.shp`、`.dbf`、`.prj`、`.cpg` 等。典型结构：

```text
Carto/
├─ Shapefile/
│  ├─ Area_Boundary.shp / .dbf / .prj / .cpg
│  ├─ Network_Centerline.*
│  ├─ Network_Boundary.*
│  ├─ Building_Boundary.*
│  ├─ POI_Location.*
│  ├─ Route_Centerline.*
│  └─ Zoning_Boundary.*
├─ GeoTIFF/
│  ├─ Elevation.tif
│  └─ Depth.tif
└─ Styles/                       当前不应用 Carto 样式文件
```

程序识别七类 Shapefile，将路网中心线与轮廓、建筑与 POI 尽可能配对，并保留导入属性。Zoning 与手绘功能区块有独立显示开关。

地形支持当前解析器兼容的**单波段、未压缩、正方形 GeoTIFF**；不承诺支持任意 GIS 栅格格式或压缩方式。Elevation 按高程着色，Depth 表现水体；纯色陆地／水体简图从 Depth 自动生成。应使用与当前工程范围一致的 Carto 数据。

## 7. 资产提取与导入

### 提取建筑资产

> **当前验证范围：** 目前仅验证了少数官方地区资产包；游戏本体自带的资源包和第三方资产包尚未验证，暂不保证兼容。

1. 打开“资产 → 资产提取器…”，在独立窗口中选择 `.cok` 文件。
2. 设置资产包名称、输出位置。
3. 勾选二维投影、远景 LOD2、中等 LOD1 中需要的内容，至少选择一项。
4. 点击开始提取，等待完成信息并检查日志。

默认输出位置：`tools/资产提取器/output`。选齐三项时，一个资产包输出三个文件：

```text
包编号.cs2assets
包编号-lod2.glb
包编号-lod1.glb
```

只导出建筑，不以附加模块或道具作为独立建筑列出。保留建筑投影、占地、高度、来源编号与用途等信息；住宅／雇佣容量有数据时保留，缺失时留空。导出 LOD 是简化几何，不提供完整游戏材质和贴图。

游戏原始文件只读；输出目录应放在游戏目录之外。默认中间数据和日志在提取器的 `工作缓存` 中。不要在提取过程中移动工具目录或清理该缓存。取消勾选某个输出选项，不会删除此前已生成的同名旧输出。

资产提取器只在手动打开时启动。关闭地图窗口不会强制中断独立提取任务；完成后可单独关闭提取器。

### 加入工程与摆放

从“资产 → 导入建筑资产包…”多选同一批次的文件。支持以下组合：

| 组合 | 是否支持 |
| --- | --- |
| 只有二维投影 | 支持 |
| 二维投影 + LOD2 | 支持 |
| 二维投影 + LOD2 + LOD1 | 支持 |
| 只有 GLB，或投影 + LOD1 缺少 LOD2 | 不支持作为完整导入组合 |

导入包和模型的编号必须匹配。任意第三方 GLB 不等同于本工具的建筑 LOD 数据。

点击左侧资产包，在右侧选择建筑，再在地图上放置；首次选取可能自动放大到适合摆放的比例。右键取消选择，资产包面板保持原位置。摆放时 `R` 旋转 90°，`Shift+R` 旋转 15°。已摆放建筑可修改位置、角度、名称及离地偏移，并显示来源资产包和具体资产编号。

### 资产包管理

“资产 → 资产包管理…”提供搜索、批量选择、未摆放包筛选，以及建筑数、已摆放数量和 LOD 大小。

默认不允许移除仍有摆放建筑的包。明确勾选“同时移除所选包已经摆放的建筑”后，才会一并移除这些实例，并在执行前确认。操作可撤销，之后需保存工程。

**资产管理清理的是工程引用，不会自动删除导入源文件、提取器输出或工程旁残留的模型文件。**因此不等于自动释放相应磁盘空间。

## 8. 三维预览与性能

从“视图 → 三维只读视窗”进入。三维仅供查看，编辑在二维完成。

- 左键拖动旋转，右键或 Shift 拖动平移，滚轮缩放。
- 可开关地形、水面、建筑、道路和区划边界；隐藏大类也会约束相应显示。
- 自动 LOD 近处优先 LOD1、远处优先 LOD2，也可切换预览级别。
- 无可用模型时按投影与高度生成简化体块。桥隧道路为层级示意，不是游戏道路结构的完整复原。
- “定位二维选中”需要先在二维选择对象。

性能机制：LOD 导入先读索引，显示建筑时再分段读取几何，不把整包 GLB 转为 Base64 长期嵌入状态；几何缓存预算约 96 MB，达到预算时可能使用较低级别或简化体块。二维缩放和平移按帧更新视野，停止后再刷新文字和线宽。关闭三维时释放图形环境及几何缓存。

运行文件和资产文件占用磁盘，不等于所有文件都常驻内存。Electron 的界面、图形等辅助进程属于程序正常运行的一部分。程序未提供大规模城市或低配置机器的流畅度保证；较多 SVG 对象、高分辨率底图、复杂模型及一次性大量导入仍可能卡顿。

## 9. 工程保存、备份与迁移

新工程第一次保存会要求选择位置；已打开的工程按保存会覆盖原文件；另存为选择新文件。没有浏览器自动备份替代手动保存，请及时保存，退出时会提示未保存修改。

普通 `.cs2map` 包含规划数据、图像和资产投影等内容。桌面版将大模型放在工程旁的同名 `.assets` 文件夹中：

```text
projects/我的地图/
├─ 我的地图.cs2map
└─ 我的地图.assets/
   ├─ pack-编号-lod2.glb
   └─ pack-编号-lod1.glb
```

**复制、备份、迁移工程必须同时带上 `.cs2map` 和同名 `.assets` 文件夹。**随意只改工程文件名或移动模型文件可能破坏相对引用；改名建议使用另存为。

旧版内嵌模型的完整 `.cs2map` 可导入；桌面版保存时会转成独立模型资源。含独立模型引用的新工程应使用绿色桌面版打开，不要用旧网页版覆盖保存。

项目文件夹模式还可能包含 `project.folder.json`、`assets/*.cs2assets` 和模型文件。采用该模式时应迁移整个项目文件夹，保持相对位置。

`userdata` 存储程序缓存，不应被当作工程备份。新发布包升级时先保存并退出，将旧工程连同资源复制到新包或直接从原位置打开即可；不必搬迁旧 `userdata`。

## 10. 导出

### PNG

选择“文件 → 导出 PNG…”，分辨率可选 **2048、4096、8192**。导出完整正方形地图，包含当前可见图层，不含编辑节点。高分辨率导出比屏幕显示需要更多内存和时间。

### 将 PNG 用于 Image Overlay

[Image Overlay（Paradox Mods）](https://mods.paradoxplaza.com/mods/74539/Windows) 可把 PNG 图片叠加到游戏地图上，作为建设参考，并可调整图片的位置、大小、旋转和透明度。

1. 在本工具中设置需要显示的图层，从“文件 → 导出 PNG…”导出完整地图。
2. 将 PNG 复制到游戏用户数据目录下的 `Overlays` 文件夹：

   ```text
   %USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Overlays
   ```

3. 在游戏中启用 Image Overlay，在模组设置里刷新文件列表并选择这张 PNG。
4. 按 `Ctrl+O` 显示或隐藏叠加图，按需调整透明度及位置，对照规划进行建设。

完整地图导出可选 2048、4096、8192 分辨率。Image Overlay 默认以边长 14.336 km 的原版可玩区域居中显示；保持工程范围与游戏地图一致，更便于对齐。这是规划图片叠加显示，实际道路和建筑仍由你在游戏中建设。更多设置见 [Image Overlay 作者说明](https://github.com/algernon-A/ImageOverlay/blob/master/README.md)。

**Carto 导出地图数据 → 本工具规划 → 导出 PNG → Image Overlay 叠加到游戏地图。**

### Carto / Shapefile

选择“文件 → 导出 Carto…”。输出 ZIP 中包含七组 Shapefile 及配套文件，可选携带已有原始地形数据。

导出的是工程对象，**隐藏图层也会包含在 Carto 数据导出中**；显示开关只控制绘制与 PNG 可见内容。导出不表示游戏会自动接收或应用规划修改。

## 11. 常见问题

**EXE 为什么超过两百 MB？**  
主要是 Electron 自带的 Chromium、JavaScript 和图形运行环境。免安装意味着运行依赖随包携带，不代表单文件或小体积。

**启动失败或文件操作失败？**  
确认已完整解压、使用 Windows x64，并且目录可写。不要只拷贝 EXE，不要在压缩包或只读目录中运行。查看 `userdata/logs`、`userdata/crashes` 中实际生成的诊断文件；它们不一定在每次失败时都有记录。

**重新打开工程提示模型缺失？**  
检查同名 `.assets` 文件夹、模型文件名及相对位置，或找回完整备份。不要以为空的缓存目录可以替代模型资源。

**资产提取失败？**  
查看提取窗口指向的任务日志。启动失败时检查 `tools/资产提取器/startup-error.log`。不同版本游戏、模组及自定义 COK 的结构可能不兼容，工具不承诺支持全部包。

**地图仍卡顿？**  
关闭暂时不用的图层和标签，避免同时叠加多张地形显示；三维优先使用 LOD2，关掉不用的三维视窗和提取器。资产移除后的撤销记录会在本次会话保留恢复所需数据；保存并重新打开工程可结束这部分撤销保留。

**清理资产包后文件夹没有变小？**  
移除工程引用不删除原文件和模型副本。确认工程备份完整后再自行整理；不要在工程仍引用文件时删除模型。
