# 地图规划设计器使用手册 · v0.5.1

解压到可写目录后运行 `MapDesign.exe`。程序启动时检查 Microsoft Edge WebView2，缺少时可从提示打开微软下载页。安装运行时后重新启动即可。若随包附有 `WebView2Loader.dll`，请与 EXE 放在同一目录。

- **工程**。用“文件”打开 `.cs2map` 或工程文件夹，或进入“工程设置”调整名称和边长。`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。旧版工程可以打开，保存时保留图层、底图、地形、二维建筑和属性。要保留历史三维数据，可用另存为创建新工程。
- **导入**。通过“图层”导入正方形底图或 Carto 文件夹。可识别 Shapefile、Elevation.tif 和 Depth.tif，更新同一张地图的 Carto 现状时保留手绘规划。
- **绘制**。从左侧选图层，在右侧选择绘制操作。单击添加节点，Enter 或双击完成，Esc 取消。V 选择、H 平移、M 测距。拖动节点或对象修改，Delete 删除，Ctrl+Z 撤销。
- **道路接入与节点**。开启吸附后，绘制道路可接到已有同层道路的线段。完成绘制时会给可编辑的目标道路补节点。选中线条或片区后，双击其边线可添加节点。
- **片区**。单击片区内部或边界附近可选中。上方有其他对象时，按住 Alt 单击可选片区。右侧展开“片区规划统计”，可查看道路长度、区块面积和建筑数量。
- **编辑与显示**。网格、吸附、名称与标签、预留走廊、缩放和全屏都在“编辑”菜单。区块透明度、底图和图层管理在“图层”菜单。
- **建筑**。内置 21 包、6280 项二维资产。内置 DLC、官方资产包、第三方资产包默认折叠。搜索包名后选择建筑，单击地图摆放，R 或 Shift+R 旋转，右键取消。导入 `.cs2assets` 或 JSON 投影文件后，可在右侧改归类。
- **独立规划工作区**。从“工具 → 规划工具”进入区域规划。现有工程的对象作为只读参考。点击“暂存到规划图层”把预览变为可编辑对象，再用地图编辑和属性工具调整。左栏可分别显示和隐藏参考及规划图层。点击“返回工程”可随时切回。
- **全局规划**。本版本目前不可用，界面保留入口。区域规划生成的是初级草案，仅供参考。
- **保存、导出和合并**。“保存工作区”生成含参考地图、地形和规划对象的 `.cs2plan`，可继续打开编辑。“导出可见规划”生成可叠加导入的 `.cs2map`。“合并可见规划”将左栏勾选的规划图层写入当前工程，合并可整体撤销。
- **区域规划**。选择片区后可设置各用途的目标面积比例和建筑限高。用途比例合计为 100%，其中包含绿地。预览同时显示目标比例和生成地块的实际比例。重复点击“生成预览”会尝试不同的道路布局、地块和建筑组合，保留设置的用途比例、建筑限高和接点条件。自动路网参考南北轴、外围道路和片区边界，住宅与校园限制对外接点，商业街区优先多侧连通。接点在预览中标出。外部接点默认按片区用途和面积自动设置，可切换到手动输入 0–30 处，或选择“不限”按现状道路可接入的位置布置。最近使用的模式和手动数量会在本机记住。设为 0 时只沿现状道路布置。程序先按地形和现状障碍生成可接入的内部支路，再沿新旧道路按用途、资产占地、二维轮廓和高度选择楼栋，并用可建设范围检查退让。预览显示具体楼栋、道路、草地、建议植树点与陆地面积估算。未找到可靠接点的道路候选会略过，缺乏合适资产的地块可保留待建。树冠是建议尺寸，树种及建筑入口需按游戏实况核对。采纳可编辑，也可一步撤销。
  - 同一组团优先使用相近高度的楼栋，滨水和片区边缘适当降高。预览显示主要用途的常见建筑高度。
  - 内部道路以双车道支路为主。住宅、校园和商业区可在部分短连接使用无中心线的窄巷，货运路线保持正常支路宽度。较大且有集散需求的片区可形成一条四车道支路线；具备两端合适接入的大型商业或产业片区可采用次干道。预览按类型展示路段，默认宽度可在路网图层属性中设置。
  - 大学主楼、学校、诊所等有数量限制。计算时包含周边现状与已暂存的同类设施。射电望远镜等专项资产可在资产库手动摆放。研发办公和校园配套使用普通办公资产作为体量参考。
  - 设置绿地比例后，规划会沿街预留部分绿地，排完楼栋后再从可用的边角和楼间空隙补充多边形绿地。绿地入口、步行连通性和实际可用面积需在采纳前核对。
- **第三方资产提取**。在“工具 → 资产提取”选择 .cok 文件或文件夹，再选择输出文件夹。每包生成一个二维 .cs2assets，可从“资产 → 导入建筑资产包”使用。适用于建筑定义和模型都在包内的第三方资产。
- **取名**。在“工具 → 取名工具”选择 14 种地区风格和 23 类对象，支持中英对照，每次随机生成 16、32 或 64 个名称。点“查看全部”可以在当前风格、对象类型和语言下搜索或翻页，也可以复制名称或应用到选中的可编辑对象。
- **导出**。从“文件”导出七组 Carto Shapefile 或 2048、4096、8192 PNG。PNG 可放到 Image Overlay 的 `Overlays` 目录供游戏中对照建设。

程序的 WebView2 配置和恢复草稿保存在 EXE 旁的 `userdata/webview`。异常退出后，下次启动可选择恢复草稿并另存为工程。项目文件由用户选择位置保存。程序内的“帮助 → 操作说明”提供快捷键和操作提示。

Tauri 版保存时仅对高程和水深 GeoTIFF 做无损压缩，地图对象、设置和 PNG 按原格式保存。已内置的相同资产定义由程序提供，第三方资产包及本地修改过的定义随工程保留。工程文件夹保存时，主工程记录本次使用的资产版本。原有资产文件留在磁盘上。
