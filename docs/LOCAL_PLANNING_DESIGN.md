# 区域规划的街区设计规则

本文把现实城市设计原则转化为《Cities: Skylines II》区域草案的默认规则。地块尺寸、建筑高度带与设施数量由游戏资产、片区面积和现状决定，以下具体默认值属于生成器设定。

## 现实街区怎样组织

**建筑高度有主调，也有过渡。** 街区由建筑线、退让、地块粒度、主导高度和少数高点共同构成。商业主街需要连续的临街界面，低密住宅更适合前院和有间隔的建筑线。高点可用在车站、枢纽、广场等明确节点，低密住宅边缘、滨水、公园视线一侧可逐步降高。条件也可反过来，例如有明确滨水地标设计时单独处理。 [英国 National Model Design Code](https://www.gov.uk/government/publications/national-model-design-code/national-model-design-code-part-2-guidance-notes-html-accessible-version) · [新加坡 URA 市中心城市设计指引](https://www.ura.gov.sg/guidelines/urban-design/downtown-core/)

**绿地有不同层级和用途。** 小区内部有共享庭院、活动草地和小游园；街角可有三角口袋公园或广场；两栋建筑之间可留植树、步行通道或缓冲绿地；岸线、坡脚可形成连续带状绿地。开放空间的好坏还取决于能否步行进入、边界是否清楚及能否连接其他公共空间。对住宅、学校或商业的需求，应在排楼前预留少量关键公共空间。建筑落位后，再用余地补足绿化和步行联系。 [英国 National Model Design Code](https://www.gov.uk/government/publications/national-model-design-code/national-model-design-code-part-2-guidance-notes-html-accessible-version) · [新加坡 NParks 公园连道](https://pcn.nparks.gov.sg/recreational-connectivity/aboutrecreationalconnectivity/) · [纽约 Putnam 三角广场](https://www.nyc.gov/site/cecm/permitting/putnam-triangle-plaza.page)

**设施按服务范围与场地需求布局。** 小商店、住宅、办公楼和一般厂房可以成组出现。社区中心、小学等服务一定范围的居民，要看附近是否已有同类设施及其可达性。大学、医院等更大的设施一般是独立组团。射电望远镜、对撞机等专项设施有独立场地条件，可能需要限制干扰或预留专用范围，应由独立需求触发。射电天文观测站可以是一组设备，计数单位应是设施或园区。 [新南威尔士州社会基础设施研究，第 5.2 节](https://www.planning.nsw.gov.au/sites/default/files/2023-04/sydenham-to-bankstown-social-infrastructure-study.pdf) · [美国国家射电天文台的无线电静默区](https://science.nrao.edu/spectrum/services/nrqz)

## 不同区划怎么生成

| 片区类型 | 街道和建筑主调 | 开放空间与设施布置 |
| --- | --- | --- |
| 低密住宅、村镇 | 顺地形的住宅支路，同组建筑以相近的低层体量为主。少量商服靠入口或主街。 | 前后院、街角绿地、带步行出入口的游园。一小片可用草地比数块孤立碎草地更有价值。 |
| 中高密住宅 | 楼栋按街坊或组团摆，同组用一到两档相近高度。靠低密邻区、公园和水岸的一侧通常降低；高点集中在明确节点。 | 先留共享庭院或社区绿地，再安排住宅。学校、诊所按服务需求和已建设施情况选址。 |
| 老城、商住主街 | 沿主街建立相近的檐口高度和较连续的建筑线，支路可有小尺度变化。街尾或广场可留一个较明显地标。 | 桥头、斜交街角和窄巷出口可有小广场或口袋绿地。公共空间要接到步行路径。 |
| 商业中心、办公区 | 较开放的街网，临街商业较连续，较高办公楼在车站、广场和主街节点形成组群。 | 公共广场与步行连廊串联。装卸和停车出入口安排在次要街面。 |
| 校园、医疗园区 | 先定入口、核心楼与主要步行方向，再分组安排教学、科研、宿舍、门诊或后勤。组内高度相近，重点楼和技术设施单独控制。 | 中心草坪、学院庭院、运动场要与步行轴相连。按校园实际角色摆一个组团，将会堂或实验设施作为项目资产安排。 |
| 产业园、货运物流 | 先定货运入口、转弯和装卸空间。仓库与厂房可统一为大片低层体量，办公和职工配套集中在便于到达的位置。 | 绿带用于住宅过渡、步行和排水。装卸面和消防通道优先保留。 [JTC 产业园总体规划](https://www.jtc.gov.sg/about-jtc/master-planning-and-development) |
| 滨水公园、文旅、生态区 | 先保岸线、地形和游览路径，再摆桥头、市集、服务点及少量主景建筑。建筑高度服从主视线。 | 带状滨水绿地、弯曲岸线公园和活动节点可以组合。步行可达的开放空间和生态保留地分别统计。 |

## 程序怎么重构

原有实现按用途和临街段逐个挑选资产。高度多数用于筛选限高，街道或楼群缺少主导高度。内置“科研”分类只包括地质研究中心、大型强子对撞机和射电望远镜，园区选中这一用途后容易重复消耗这几个候选。绿化阶段则用矩形地块和孤立方格扫剩余空间。

1. **区划先选形态。** 使用“低密住宅、组团住宅、老城主街、开放商业、校园、产业物流、滨水景观”等形态预设。原有用途比例继续决定面积预算。预设给出建筑线、街坊尺度、组团高度带、开放空间优先级和设施角色。混合区按街坊或街道位置分配局部角色。
2. **建立按角色查找的资产索引。** 优先使用稳定资产编号标记普通重复建筑、社区服务、大型组团、专项地标和主楼附属物。已知专项设施默认只有明确选择后才进入候选；原有资产库仍可手动摆放。不能确认性质的第三方资产供手动选择。推荐设施数量前，检查工程参考、已暂存规划以及当前草案，图层隐藏也不影响计数。公建设施缺乏人口或服务区数据时给预留建议。
3. **先确定组团体量，再在组团内选楼。** 在沿街和内部街坊分配主导高度带、边缘过渡带及允许的少量高点。利用资产高度和二维轮廓检查邻楼间距、建筑线与现状的衔接。选小范围高度带内的不同资产来形成节奏。用户限高继续作为硬约束。以限高 30 米的普通住宅为例，可用一档 18–24 米作为街坊主调，靠低密边界降一档，较高楼只在指定位置出现。18–24 米是示例，生成时按可用资产和现状校准。
4. **按空间生成绿地多边形。** 先给必需的公共绿地和连通带留位置。排完道路、楼栋、出入口、装卸面及退让后，从片区可用地中扣除上述地面，合并可连通的空白并简化外边界；支持三角、L 形、弯带、院落等边界。按净宽、面积、入口和连通性判断它是可停留的小公园、窄缓冲带、共享庭院还是留白。种树前再核对冠幅、视线和道路净空。已规划的建筑用地里可有退让绿化，统计时同一地面只算一次。
5. **方案评价和随机变化顺序。** 先通过边界、地形、用途、建筑限高、占地间距和设施数量的校验。候选之间以组团协调、步行可达、街道界面、绿地连贯和接入质量为主要指标，同时报告剩余面积。让重复生成探索“林荫主街、内院组团、沿河绿带”等不同布局，楼型和树木可以在同一种布局里继续变化。

## 第一轮验证

用同一个混合住宅片区和现有“滨海理工大学片区”比较三套草案。在同一个片区重复生成、暂存后再生成，以及相邻片区分别生成时，核对专项设施的数量。进一步核对同一街坊的高度集中度，高度过渡位置，建筑之间的不规则绿地是否有入口，以及狭窄边角是否恰当地显示为缓冲或留白。预览报告建议给出主要高度带、公共与组团绿地面积、专项设施清单和未分配地面。
