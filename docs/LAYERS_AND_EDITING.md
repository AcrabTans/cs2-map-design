# 图层管理与路网编辑优化（2026-11-02）

“图层”菜单新增“图层管理”和“底图管理”。网页版也提供对应的“图层”菜单。

- 图层管理：按大类和子图层控制显示、锁定、名称标签，并查看对象数量；点击分类名称进入右侧属性与对象列表。
- 底图管理：预览、选择、重命名、导入和移除自定义底图。移除只影响当前工程，可撤销；不删除原图片。
- 建筑 → 市政：可展开铁路设施、航空设施、水运设施、公交地铁设施、市政公用设施、其他市政建筑，以及火车站牌、航空停靠点、公交地铁站点、水运停靠点、红绿灯、其他点位。开关随工程保存，父图层和数据来源开关仍然生效。红绿灯默认隐藏，可单独开启。

这些分类不拆分或改写 Carto 原始对象，也不改变其 Shapefile 图层身份。

## 卡顿原因与处理

用于排查的《地图工程-统筹规划01.cs2map》有 1,554 个对象、53,221 个坐标点，其中路网 861 个对象、44,496 个中心线坐标点。270 是手绘规划对象数，而非节点总数。

原流程在每次拖动事件中重建全部 SVG 对象，并重新计算所有路口。现在拖动时每帧只更新当前对象的预览；松开后才校验范围并重建路口。路口结果在仅选择或缩放时复用，几何编辑和可见路网改变时重算。节点吸附改为邻域索引，隐藏对象与当前移动对象不参与吸附。

同一工程、本机 Node 计算对比：路口计算由约 647 ms 降到 341 ms，两次得到相同的 935 个交叉位置；100 次吸附查询由约 173 ms 降到 0.28 ms，索引首次构建约 11 ms。它们是计算环节的测量，不代表浏览器帧率；拖动时已经不再逐次执行整图路口计算。

验证：51 项自动检查通过；实际免安装版窗口核对菜单、管理窗口、市政子类展开与工程载入。原工程未改写。既有窗口需保存后重启，才会载入新界面和编辑流程。
