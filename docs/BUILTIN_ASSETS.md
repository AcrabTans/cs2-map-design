# 内置二维建筑资产

v0.4.0 内置 21 包、6280 项二维建筑投影。本体 1013 项，包含 43 项独立占地扩展。11 个 DLC 共 592 项，9 个官方地区包共 4675 项。

投影保留轮廓、占地、高度、来源编号和可用的人数上限。独立占地扩展保留对应主楼编号。数据位于 `source/src/building-asset-data.js`。

本体建筑直接显示，DLC、官方和第三方资产包默认折叠。搜索资产包后可以在右侧按用途和编号查找建筑。导入的 `.cs2assets` 或 JSON 资产包随工程保存。

旧工程中的内嵌或外部模型引用会跳过，原有二维投影和建筑属性继续可用。资产提取器作为独立工具维护。
