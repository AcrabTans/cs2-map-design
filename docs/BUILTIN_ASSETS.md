# 内置二维建筑资产

程序内置 21 包、6280 项二维建筑投影。本体 1013 项，包含 43 项独立占地扩展。其中 39 项按建筑主模型生成投影，另外 4 项操场或公园使用游戏地表轮廓。11 个 DLC 共 592 项，9 个官方地区包共 4675 项。

投影保留轮廓、占地、高度、来源编号和可用的人数上限。独立占地扩展保留对应主楼编号。数据位于 `source/src/building-asset-data.js`。

本体建筑直接显示，DLC、官方和第三方资产包默认折叠。搜索资产包后可以在右侧按用途和编号查找建筑。

将提取的 `.cs2assets` 放在 MapDesign.exe 旁的 `lod` 文件夹内，桌面版启动时会自动读取。各工程共用这些预置投影，工程只保存实际摆放建筑的定义。手动导入 `.cs2assets` 或 JSON 时，资产包随当前工程保存。

## 3D 模型

将所需的 GLB 放进与 MapDesign.exe 同级的 `lod` 文件夹。每次启动后首次打开 3D 视图时，程序会识别其中的兼容文件，并按包编号和建筑编号匹配，之后的工程可共用。模型网格按需读取，文件独立放在程序目录。也可以在「工具 → 3D 视图 → 加载 LOD 文件」临时选文件。

| 类别 | LOD1 | LOD2 |
| --- | --- | --- |
| 游戏本体 | cs2-basegame-lod1.glb | cs2-basegame-lod2.glb |
| 11 个 DLC | cs2-dlc-lod1.glb | cs2-dlc-lod2.glb |
| 9 个官方地区包 | cs2-official-regions-lod1.glb | cs2-official-regions-lod2.glb |

当前运行期间可重复使用已加载的模型。缺少对应级别时，3D 视图会尝试已加载的另一级，再按二维轮廓和高度显示体块。第三方资产可在「工具 → 资产提取」扫描自己的 Mod 缓存后提取。
